| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public GitHub issue
2. Use [GitHub's private vulnerability reporting](https://github.com/savitojs/gtime/security/advisories/new) to submit a report
3. Include steps to reproduce the issue and any relevant details

You can expect an initial response within 72 hours. We will work with you to understand the issue and coordinate a fix before any public disclosure.
